Ключевые возможности приложения включают в себя личную библиотеку для удобного добавления и хранения слов и их переводов в локальной базе данных (Room DB), а также умный поиск, обеспечивающий мгновенную фильтрацию по всей базе данных прямо на ходу по мере ввода первых букв слова или перевода. Кроме того, в приложении реализован режим «Квиз» (тренажер) – интерактивное тестирование, построенное на механике активного вспоминания, где перевод на английском вводится вручную, получается мгновенный цветовой отклик (зеленая вспышка при успехе) и отслеживается количество оставшихся слов, а встроенная интеграция со словарем предоставляет быстрый доступ к авторитетному Cambridge Dictionary прямо из приложения для оперативной проверки транскрипций и контекста.
